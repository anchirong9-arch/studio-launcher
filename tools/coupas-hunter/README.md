# 🛒 쿠파스 가성비 상품 헌터

쿠팡 파트너스 상품을 **가성비·박리다매** 기준으로 골라 주고, 고른 상품의
**쓰레드 · 유튜브 · 틱톡 · shop-links 4채널 단축 링크**를 한 번에 뽑아 주는 로컬 도구입니다.

- 🌐 웹 UI : https://anchirong9-arch.github.io/coupas-hunter/
- 💻 서버 : 이 PC에서 `실행하기.bat` 더블클릭 (Python 3만 있으면 됩니다. 추가 설치 없음)
- 🔌 포트 **8767**, `127.0.0.1` 에만 열립니다 → 같은 PC 밖에서는 접근할 수 없습니다.

## 처음 한 번만

1. `실행하기.bat` 을 더블클릭합니다. (Python이 없으면 안내가 나옵니다 → python.org 설치 시 `Add python.exe to PATH` 체크)
2. 브라우저가 자동으로 열립니다. `http://127.0.0.1:8767/`
3. 오른쪽 위 **🔑 키 설정** → 쿠팡 파트너스 `Open API`의 **Access Key / Secret Key** 입력 → 저장
   - 키는 이 PC의 `coupas-api-key.env` 에 **권한 600** 으로만 저장됩니다.
   - 저장 전에 쿠팡 API로 실제 호출해 검증하므로, 잘못된 키는 저장되지 않습니다.

## 쓰는 법

| 버튼 | 하는 일 |
| --- | --- |
| 💸 1만 원 이하 | 10,000원 이하만 남깁니다 |
| 🚀 로켓배송만 | 로켓배송 상품만 남깁니다 |
| 📉 가격 낮은순 / 🔥 할인율 순 | 정렬을 바꿉니다 |
| 🖼 (카드 이미지 버튼) | 상품 이미지 URL을 복사합니다 |
| 🔗 4채널 링크 | 쓰레드·유튜브·틱톡·shop-links 단축 링크를 4개 만들고, 하나씩/한 번에 복사합니다 |
| `{}` shop-links JSON 복사 | `shop-links` 저장소의 `products.json` 에 바로 붙일 수 있는 항목을 복사합니다 |

**가성비 점수** = (최저가 ÷ 이 상품 가격) × 70점 + 인기순위 보정 × 30점

쿠팡 검색 API는 정가(할인 전 가격)를 주지 않는 경우가 많아, 그때는 `할인율 순` 대신
가성비 점수순으로 정렬하고 화면에 그 사실을 표시합니다.

## 서버 주소

| 주소 | 설명 |
| --- | --- |
| `GET /health` | 서버·키 상태 (키 값은 반환하지 않고 앞 4자리만) |
| `POST /config` | `{"access_key":"…","secret_key":"…"}` → 이 PC에 저장 |
| `POST /config/clear` | 이 PC의 키 삭제 |
| `GET /api/search?q=무선마우스&max_price=10000&rocket=1&sort=value` | 상품 검색 (정렬 `value`, `price`, `discount`, `rank`) |
| `POST /api/links` | `{"product_id":"9037114012"}` → 4채널 단축 링크 |
| `GET /download/zip` | 이 프로그램 ZIP (키 파일 제외) |

## 보안

- Access/Secret Key는 **저장소에 절대 올라가지 않습니다.** `.gitignore` 가 `*.env` 를 막고 있고, ZIP에도 키 파일을 넣지 않습니다.
- 서버는 `127.0.0.1` 에만 바인딩되고, 키 값은 로그·응답 어디에도 찍히지 않습니다.
- GitHub Pages 화면은 UI만 내려받고, 실제 쿠팡 호출은 항상 이 PC의 서버가 합니다. 서버가 꺼져 있으면 검색이 되지 않습니다.

## 파일

```

app.js           화면 로직
실행하기.bat      PC 1클릭 실행 (run.bat 과 동일)
run.bat          영문 이름 실행 파일
favicon.svg      아이콘
```

쿠팡 파트너스 활동의 일환으로, 이 도구로 만든 링크를 통해 구매가 일어나면 수수료를 받을 수 있습니다.
